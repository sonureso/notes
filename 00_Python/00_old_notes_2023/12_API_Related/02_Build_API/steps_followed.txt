♦ Creating first simple API:
1. create a folder "my_api", inside it create a main.py file with below content:
----------------------------------
from fastapi import FastAPI
app = FastAPI()
@app.get("/")
def get_root():
    return "Welcome to my API."
----------------------------------
2. run this in CMD: 
	uvicorn main:app --reload
	(uvicorn filename:app --reload)
3. You can check on localhost: http://127.0.0.1:8000/
